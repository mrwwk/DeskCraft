EasyVis DeskCraft - Task Visualizer

Browse DeskCraft standard & interactive task results

How to Use / 使用说明

1. Fill in Config JSON Path and Examples Directory in the left panel, click Load Data

在左侧填入 Config 路径和 Examples 目录，点击 Load Data 加载

2. Click a task ID in the sidebar to view its details

点击左侧 task ID 查看详情

3. Click ▶ Config / Evaluator to expand sections

点击折叠标题展开对应内容

4. Click any ✨ button to trigger AI analysis (select language in top-right)

点击 ✨ 按钮触发 AI 分析（右上角选语言）

5. Click ⚙ LLM Settings to switch AI model/provider, then Apply

点击 ⚙ LLM Settings 切换 AI 模型，点 Apply 确认

6. Share the browser URL to let others see the same task view

复制浏览器地址栏链接可分享当前视图
